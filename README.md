  - A 題材純、股價還沒反映（0）
  - B 題材是真的、股價已反映（10：台達電、光寶科、順達、松川精密、禾伸堂、貿聯-KY、宏致、高力、致茂、Bloom Energy）

## 頁面上不顯示來源（2026-10-05）
來源都留在原始檔裡，但畫面上不顯示：各站補充的來源牌子、公司卡片的來源行、圖說來源、頁尾的資料來源清單，以及括號裡純粹寫「誰、哪一天」的出處（例如「（富邦 9/30）」）。
